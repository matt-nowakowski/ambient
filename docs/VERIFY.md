# How to verify Ambient's privacy claims

Every promise in the privacy policy ([tryambient.ai/privacy](https://tryambient.ai/privacy),
source in `web/app/privacy/page.tsx`) is listed below with the code that keeps
it and a way to check it yourself: a search, a test, or the app's Privacy
Center (Settings › Privacy). Paths are relative to the repository root; Rust
files are in `src-tauri/src/`. [ARCHITECTURE.md](ARCHITECTURE.md) has the
picture.

## The short way

1. **Only 15 files can reach the network.** `bun run check:egress`
   (`scripts/check-egress.ts`, run in CI by `.github/workflows/code-quality.yml`)
   fails if any HTTP client, socket or networking plugin appears in the app's
   Rust, Swift or vendored code outside its allowlist, if the audio modules
   refer to the network or to any module that sends data, or if the interface
   (`src/`) makes a request of its own. The allowlist says what each file sends.
2. **Each of those files ledgers what it sends** with `recall::log_request`
   before sending, and the Privacy Center shows that ledger. The table under
   [Every network request](#every-network-request) lists them all.
3. **Run the tests named below**: `cd src-tauri && cargo test <name>`.

Everything else in the app runs on your computer. The links Ambient opens
in your browser (Google Drive and Gmail searches, checkout, the website)
are your browser's requests, not the app's.

## What you can't verify from this repository

- **That the build you run was made from this code.** Releases are built by
  `.github/workflows/release.yml` from tagged commits, and macOS builds are
  signed and notarised, but builds are not reproducible yet, so you can't
  rebuild one byte for byte. The Privacy Center ledger and an outbound
  firewall (Little Snitch, LuLu, OpenSnitch) let you watch the real app.
- **That the server runs this code.** The server is in `web/` and you can read
  every route the app calls, but you can't see what is deployed. What the
  server keeps and for how long is in the privacy policy; the database schema
  is in `web/lib/db.ts` and the routes.
- **What our providers do.** Baseten (model), Tavily (search), Resend (email),
  Polar (billing), Vercel (hosting), Neon (database) and Cloudflare (downloads)
  process data under their own terms.
- **Apple Intelligence.** Ambient calls Apple's on-device model
  (`apple_intelligence.rs`, `swift/apple_intelligence.swift`) and sends Apple
  nothing; what macOS does inside its model is Apple's.
