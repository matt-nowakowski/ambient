# Contributing

This code is public to read, not to change: the licence ([LICENSE](LICENSE))
doesn't allow modified copies, so we can't accept pull requests.
Found a bug or have an idea? Use **Send feedback** in the app (it shows you
exactly what it sends), or email hello@tryambient.ai.
Security problems: see [SECURITY.md](SECURITY.md) and report them privately.
Thank you for reading the code. That's what it's here for.
